# PBI-0001: Add a pure hello.characters.count_characters(text: str) -> int that counts code points which are not whitespace (str.isspace() false) and whose unicodedata category does not start with 'M'. Change hello.cli.main so every successful run prints exactly 'words: <N> characters: <M>' plus a newline, with N from hello.counter.count_words and M from count_characters on the same decoded text. Update the README to document the new line, the visible-character rule and the end of the bare-integer output. Add or update the tests and feature files for the new behaviour, including tests/test_characters.py::test_combining_marks_do_not_add_to_count, tests/test_cli.py::test_success_output_is_labeled_combined_line and tests/arch/test_layering.py::test_characters_module_performs_no_io. Update existing tests that assert the old bare-integer output.

## Refinement Protocol

This PBI deliberately bundles the whole SPEC-0002 change as one increment, because the handoff asks for as few PBIs as possible and the ADR-backed tests need both the character counter and the CLI change. If the character rule or the output line itself needs to change, file a discovery report as a contract-level change rather than editing SPEC-0002 directly. If a decision conflicts with ADR-0001 to ADR-0006, raise an ADR change rather than working around it in code. Code-level choices such as helper names and test layout stay within this PBI.
