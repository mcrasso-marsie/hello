## Verification

- [ ] LINE_TERMINATORS is annotated frozenset[str] and contains exactly LF, VT, FF, CR, FS, GS, RS, NEL, LS, and PS; CRLF is not an element.
- [ ] count_lines(text: str) -> int counts every specified terminator, coalesces only adjacent CRLF, ignores unterminated final segments, and returns zero for empty text and blank text without terminators.
- [ ] Unit tests cover all 11 terminators, repeated blank lines, CRCRLF = 2, LFCR = 2, the mixed-terminator example = 11, and all six specified non-boundary characters.
- [ ] tests/test_lines.py::test_line_terminators_match_str_splitlines_boundaries scans U+0000 through U+10FFFF excluding surrogates and compares the complete discovered splitlines boundary set with LINE_TERMINATORS; do not sample or skip the scan.
- [ ] tests/arch/test_layering.py::test_line_counter_performs_no_io enforces standard-library-only imports and absence of references to open, print, input, sys.stdin, sys.stdout, sys.stderr, os, pathlib, and subprocess.
- [ ] Provide executable feature coverage and typed step definitions for the pure-counter Contract scenarios, preserving their exact names; the primary verification scenario passes without changes from later PBIs.
