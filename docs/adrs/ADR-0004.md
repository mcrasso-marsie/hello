# ADR-0004: One-line error and exit-status contract for CLI commands

## Context

Error handling was the least certain part of the request and stack traces block non-expert users.

## Decision

We will report every runtime error of a hello command as exactly one stderr line of the form `<command>: error: <message>: <path>` with exit status 1, never a traceback, and leave argument-usage errors to argparse with exit status 2.

## Alternatives Considered

- Let exceptions propagate: rejected, produces tracebacks
- Distinct exit codes per error type: rejected, adds a contract nobody asked for

## Consequences

### Positive

- Errors are predictable and scriptable
- Future commands share one error style

### Negative

- Error causes are not distinguishable by exit code alone

## Compliance and Verification
