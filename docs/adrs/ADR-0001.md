# ADR-0001: Standard-library-only runtime

## Context

AGENTS.md requires a documented rationale for every external dependency, and the strategy targets zero runtime dependencies for a one-argument command.

## Decision

We will keep the hello package's runtime on the Python standard library only, using argparse for argument parsing, and leave [project].dependencies empty.

## Alternatives Considered

- Use a third-party CLI framework such as click or typer: rejected, adds install weight and supply-chain surface for no benefit on one argument
- Wrap the OS `wc` utility: rejected, platform-dependent and not testable in isolation

## Consequences

### Positive

- Install is trivial and has no supply-chain surface
- Behavior is identical across platforms

### Negative

- Richer CLI features (colors, completion) must be hand-written if ever needed
