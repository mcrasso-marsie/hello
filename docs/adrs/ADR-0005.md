# ADR-0005: Visible-character rule in a pure character counter

## Context

The command must report non-whitespace visible characters, where a base letter followed by a combining accent counts once, and the character rule must stay consistent with the word rule's whitespace definition and with the architecture's no-I/O counting core.

## Decision

We will define a visible character as a code point that is not whitespace under str.isspace() and whose unicodedata category does not start with 'M', and implement it as the pure function hello.characters.count_characters in src/hello/characters.py, separate from the word counter and from all I/O.

## Alternatives Considered

- len(text) minus whitespace: rejected, it counts combining marks separately so decomposed 'é' counts 2
- Count UTF-8 bytes: rejected, it misrepresents non-ASCII text
- Unicode extended grapheme cluster segmentation: rejected, the standard library has no segmentation and a third-party dependency would violate ADR-0001
- Put the rule inside hello.counter: rejected, it mixes two rules in one module and blurs ADR-0002's single-rule boundary

## Consequences

### Positive

- Decomposed and precomposed text give the same count
- The counter is testable without files or processes
- The runtime stays standard-library only

### Negative

- Category-M exclusion is an approximation of grapheme clusters: emoji sequences joined by zero-width joiners and Hangul jamo sequences are not merged
- A combining mark that follows whitespace or starts the text counts 0 rather than 1

## Compliance and Verification

| Rule enforced | Type | Mechanism | Scope |
|---------------|------|-----------|-------|
| Combining marks do not add to the character count and whitespace is excluded. | DETERMINISTIC | tests/test_characters.py::test_combining_marks_do_not_add_to_count | character-counter |
| hello.characters performs no file, process or console I/O and imports only the standard library. | DETERMINISTIC | tests/arch/test_layering.py::test_characters_module_performs_no_io | character-counter |
