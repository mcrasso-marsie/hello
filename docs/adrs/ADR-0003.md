# ADR-0003: Minimal Quality Gate toolchain: ruff, mypy, pytest

## Context

The Toolchain table is empty so nothing is enforced; the strategy limits the gate to format, lint, type-check and test, and AGENTS.md requires a rationale for each external tool.

## Decision

We will define the Quality Gate as four commands recorded in the AGENTS.md Toolchain table — `uv run ruff format --check .`, `uv run ruff check .`, `uv run mypy --strict src tests`, `uv run pytest` — with ruff, mypy and pytest declared only in the `dev` dependency group.

## Alternatives Considered

- black plus flake8 plus isort: rejected, three tools where ruff covers formatting and linting in one
- unittest only, no type-checker: rejected, the package ships py.typed and the owner asked for best practices
- pyright instead of mypy: rejected, requires a Node-based install in some setups; mypy is pure Python and managed by uv

## Consequences

### Positive

- One fast tool covers format and lint
- Every change is checked the same way locally

### Negative

- Three dev dependencies enter uv.lock and must be kept updated
- mypy --strict demands full annotations, slowing quick edits

## Compliance and Verification

| Rule enforced | Type | Mechanism | Scope |
|---------------|------|-----------|-------|
| AGENTS.md Toolchain table lists the four Quality Gate commands | DETERMINISTIC | tests/test_agents_md.py::test_toolchain_lists_quality_gate_commands | system-wide |
| All four Quality Gate commands are run and pass before any change lands | CONVENTION | Quality Gate run per AGENTS.md Toolchain table | system-wide |
