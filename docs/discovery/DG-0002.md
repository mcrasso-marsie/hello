# Discovery Graph: DG-0002
**Graph Type:** opportunity

## Core Issue

Users want a non-whitespace character count alongside the word count when inspecting a UTF-8 file.

**Impact/Value:** Makes both measures available in one command, with character counts reflecting Unicode code points rather than UTF-8 bytes.

**Discovery Method:** Review of the requested extension and the human's clarification answers against the existing approved word-count specification.

## Patterns

### Pattern 1: file-character-count

**Applies To:** Users inspecting readable UTF-8 files with wordcount PATH.  
**Frequency/Recurrence:** Every successful command invocation.  
**Severity/Urgency:** Not specified; feature enhancement.  
**Confidence:** High, based on the explicit intent and clarification answers.  
**Current State:** The approved command reports only the integer word count; it does not report a character count.  

**Evidence Signals:**

- Extend the existing wordcount PATH command to always report both word count and character count.
- Count characters as Unicode code points (café counts as 4), excluding whitespace including spaces, tabs and newlines.
- Print a single labeled line in this exact format: words: <N> characters: <M>.
- Keep the command name wordcount and its PATH argument, and add no flags.

## Pattern Dependency Graph

The requested character count and combined output concern one extension of the existing word-count command; no dependencies between separate patterns were identified.
