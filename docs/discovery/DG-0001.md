# Discovery Graph: DG-0001
**Graph Type:** opportunity

## Core Issue

Users have no way to get the word count of a text file from the 'hello' project; they want to run a command with a file path and see how many words it contains.

**Impact/Value:** Delivers the project's first user-facing capability, on a current Python version and with a clear, documented install-and-run path so new users can adopt it without help.

**Discovery Method:** Written intent from the project owner, read against the existing tracked files and AGENTS.md.

## Patterns

### Pattern 1: word-count-from-file

**Applies To:** New command-line entry point of the hello package  
**Frequency/Recurrence:** Every time a user runs the tool on a file  
**Severity/Urgency:** High: this is the primary requested capability  
**Confidence:** High on intent; Medium on details such as what counts as a word and how errors are handled  
**Current State:** Does not exist. The package contains only an __init__.py and a py.typed marker, with no command-line entry point.  

**Evidence Signals:**

- The user wants a command-line tool that counts the words in a text file.
- The user passes the path to a text file to the tool.
- The tool prints the number of words the file contains.

### Pattern 2: project-quality-standards

**Applies To:** Project configuration (pyproject.toml, .python-version) and the AGENTS.md toolchain and Quality Gate  
**Frequency/Recurrence:** Ongoing, on every change  
**Severity/Urgency:** Medium: shapes how the feature is built and checked  
**Confidence:** Medium: 'best practices' and 'latest version' are stated without specific criteria  
**Current State:** The src layout and uv lockfile exist, but the AGENTS.md Toolchain table is empty, so no quality commands are defined.  

**Evidence Signals:**

- The project should use the latest version of Python.
- The project should follow best practices for project structure and code quality.

### Pattern 3: cli-usage-documentation

**Applies To:** README.md  
**Frequency/Recurrence:** Once per new user onboarding  
**Severity/Urgency:** Medium  
**Confidence:** High  
**Current State:** README.md exists but has no install or run instructions for a word-count CLI.  

**Evidence Signals:**

- The project should include a README.md explaining how to install and run the CLI.

## Pattern Dependency Graph

Counting words from a file is the central opportunity. The usage documentation depends on it, since the README can only explain how to install and run a command that exists. The quality standards apply across both: they set the Python version and the quality bar the tool and its documentation must meet.
